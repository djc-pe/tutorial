如何用 C++ 打印三角形：星号、金字塔和谢尔宾斯基

作者：@null_djc（系列）

  • C++
  • 编程
  • 入门

星号三角形几乎是所有课程里的第一个循环练习，在 C++ 里它也是很多人在 Codeforces 这样的评测系统上解出的第一道题。C++ 几乎什么都不提醒你：如果出了问题，程序照样继续运行。这里我们来看这些错误藏在哪里，以及怎样让编译器帮你。

我们分三个层级来讲：基础（三角形和它的陷阱）、中级（金字塔及其变体）和高级（杨辉三角、谢尔宾斯基三角形和括号的陷阱）。每个层级最后都有一个挑战。运行代码的方法：g++ -std=c++17 -Wall triangle.cpp -o triangle && ./triangle。

玩一玩三角形

读之前，先选一种类型并调整大小。下面会显示它打印出来的结果，以及实现它的 C++ 代码；你可以复制下来试试。

基础：三角形和它的陷阱

一个循环的三角形

第 1 行一个星号，第 2 行两个，第 3 行三个：行号和个数是同一个数。

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(i, '*') << "\n";
    }
}

  • for (int i = 1; i <= n; i++) 从 1 数到 5：从 1 开始，只要 i 小于或等于 5 就继续，每次加 1。
  • std::string(i, '*') 创建一个有 i 个星号的文本。先写个数，再写字符，字符用单引号。
  • "\n" 用来换行。比起 std::endl 更推荐它，因为 std::endl 还会刷新输出，打印很多行时会让程序变慢。

陷阱：少了一行

出于习惯，很多 C++ 循环从 0 开始并用 <。在这里这样写会把三角形弄坏：

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 0; i < n; i++) {
        std::cout << std::string(i, '*') << "\n";
    }
}

****

最上面多了一个空行（std::string(0, '*') 是空文本），而且少了五个星号的那一行，因为 i < n 到 4 就停了。如果结果多一行或少一行，检查循环从哪里开始，以及条件是 < 还是 <=。

倒过来

倒置的三角形，循环从 n 开始，每次减 1（i--）：

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = n; i >= 1; i--) {
        std::cout << std::string(i, '*') << "\n";
    }
}

如果用户输入 hello 呢？C++ 不会报任何错误：cin 会悄悄失败，n 保持为 0，循环一次也不执行，程序什么也不打印就结束了。要发现这个问题，就检查读取是否成功：

#include <iostream>
#include <string>

int main() {
    int n;
    if (!(std::cin >> n)) {
        std::cout << "这不是一个数字\n";
        return 1;
    }
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(i, '*') << "\n";
    }
}

用两个循环

不用 std::string(i, '*') 的话，就用一个循环套另一个循环来打印：外层遍历每一行，内层每次打印一个星号。

#include <iostream>

int main() {
    int n = 4;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            std::cout << '*';
        }
        std::cout << "\n";
    }
}

靠右对齐

金字塔

金字塔每一行多两个星号（1、3、5、7、9），这样才有中心：2 * i - 1 个星号和 n - i 个空格。

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(n - i, ' ') << std::string(2 * i - 1, '*') << "\n";
    }
}

空心

只画边框：第一行一个星号，最后一行是满的，中间每一行两边各一个星号，中间是 2 * i - 3 个空格。

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        if (i == 1) {
            std::cout << std::string(n - 1, ' ') << "*\n";
        } else if (i == n) {
            std::cout << std::string(2 * n - 1, '*') << "\n";
        } else {
            std::cout << std::string(n - i, ' ') << "*" << std::string(2 * i - 3, ' ') << "*\n";
        }
    }
}

用数字

每一行从 1 数到这一行的行号，数字之间有一个空格（第一个数前面没有，所以有 if (j > 1)）：

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            if (j > 1) std::cout << " ";
            std::cout << j;
        }
        std::cout << "\n";
    }
}

std::string 参数顺序的陷阱

std::string(3, '*') 是三个星号。反过来写 std::string('*', 3) 也能顺利编译，因为字符也是数字（'*' 的值是 42）：

#include <iostream>
#include <string>

int main() {
    std::string row('*', 3);
    std::cout << row.size() << "\n";
}
42

这是 42 个看不见的字符（第 3 号字符）。屏幕上看起来什么都没打印，但评测系统会判为错误。

高级：杨辉三角、谢尔宾斯基和括号

杨辉三角

每个数等于它正上方两个数之和，两边都是 1。每一行都由上一行算出来，放在一个 std::vector 里：

#include <iostream>
#include <string>
#include <vector>

int main() {
    int n = 5;
    std::vector<long long> row = {1};
    for (int i = 0; i < n; i++) {
        std::cout << std::string(n - i - 1, ' ');
        for (size_t k = 0; k < row.size(); k++) {
            if (k > 0) std::cout << " ";
            std::cout << row[k];
        }
        std::cout << "\n";
        std::vector<long long> next = {1};
        for (size_t k = 0; k + 1 < row.size(); k++) {
            next.push_back(row[k] + row[k + 1]);
        }
        next.push_back(1);
        row = next;
    }
}
    1
   1 1
  1 2 1
 1 3 3 1
1 4 6 4 1

long long 最大到 9223372036854775807。当 n 达到 68 或更大时，中间的数就放不下了，而 C++ 不会提醒你：结果是一个错误的数（严格来说是未定义行为）。用 unsigned long long 可以多一行；更大的行需要大整数。

用星号画谢尔宾斯基三角形

如果在杨辉三角里只把奇数涂出来，就会出现谢尔宾斯基三角形。第 i 行第 j 个数是奇数，当且仅当 (j & i) == j：

#include <iostream>
#include <string>

int main() {
    int n = 8;
    for (int i = 0; i < n; i++) {
        std::cout << std::string(n - i - 1, ' ');
        for (int j = 0; j <= i; j++) {
            if (j > 0) std::cout << " ";
            std::cout << ((j & i) == j ? "*" : " ");
        }
        std::cout << "\n";
    }
}

括号的陷阱

在 C++ 里，== 比 & 先算。不加括号，j & i == j 就是 j & (i == j)，图形会坏掉：

#include <iostream>
#include <string>

int main() {
    int n = 8;
    for (int i = 0; i < n; i++) {
        std::cout << std::string(n - i - 1, ' ');
        for (int j = 0; j <= i; j++) {
            if (j > 0) std::cout << " ";
            std::cout << (j & i == j ? "*" : " ");
        }
        std::cout << "\n";
    }
}

所以我们用 -Wall 编译：加上这个选项，g++ 正好会对这个问题发出警告。

warning: suggest parentheses around comparison in operand of ‘&’ [-Wparentheses]

警告不会让编译停下，所以很容易忽略。养成用 -Wall 编译、运行前先看看它说了什么的习惯。

那怎么画出来？

C++ 本身没有在窗口里画图的功能。有一些库可以做到（比如 SFML 或 SDL），但对第一个程序来说，安装和配置都比较麻烦。如果你想看画出来的谢尔宾斯基三角形，可以看 JavaScript 版本，它就在浏览器里直接画出来，还有用 turtle 的 Python 版本。

我们学到了什么

三角形是一张表（每一行放多少空格、多少星号），在任何语言里都一样；而在 C++ 里代价最大的错误是那些不出声的：悄悄失败的 cin、参数写反的 std::string、放不下的数，以及先被计算的运算符。一定要用 -Wall 编译：很多这样的陷阱，编译器其实早就在警告你了。

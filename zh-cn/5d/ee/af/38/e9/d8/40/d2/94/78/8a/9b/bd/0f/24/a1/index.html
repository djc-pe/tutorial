如何用 Rust 打印三角形：星号、金字塔和谢尔宾斯基

作者：@null_djc（系列）

  • Rust
  • 编程
  • 入门

星号三角形几乎是所有课程里的第一个循环练习。在 Rust 里它写起来和 Python 很像，但编译器会帮你盯住那些在其他语言里悄悄发生的事：读不出来的数字、减到零以下的减法，或者放不下的加法。这里我们用真实的错误信息来看这些陷阱。

我们分三个层级来讲：基础（三角形和它的陷阱）、中级（金字塔及其变体）和高级（格式化、杨辉三角和谢尔宾斯基三角形）。每个层级最后都有一个挑战。运行代码的方法：rustc triangle.rs && ./triangle，在项目里用 cargo run，或者在浏览器里用 Rust Playground。

玩一玩三角形

读之前，先选一种类型并调整大小。下面会显示它打印出来的结果，以及实现它的 Rust 代码；你可以复制下来试试。

基础：三角形和它的陷阱

一个循环的三角形

第 1 行一个星号，第 2 行两个，第 3 行三个：行号和个数是同一个数。

fn main() {
    let n = 5;
    for i in 1..=n {
        println!("{}", "*".repeat(i));
    }
}

  • 1..=n 是从 1 到 5 的范围，包括 5（因为有 =）。
  • "*".repeat(i) 会重复文本："*".repeat(3) 就是 "***"。
  • println! 打印并换行；{} 是放值的地方。

陷阱：少了一行

Rust 里有两种很像的范围：0..n 不包括最后一个，0..=n 包括。用第一种，三角形就错了：

fn main() {
    let n = 5;
    for i in 0..n {
        println!("{}", "*".repeat(i));
    }
}

最上面多了一个空行（"*".repeat(0) 是空文本），而且少了五个星号的那一行。如果结果多一行或少一行，先检查范围：从哪里开始，有没有 =。

倒过来

倒置的三角形，用 .rev() 把范围倒过来遍历：

fn main() {
    let n = 5;
    for i in (1..=n).rev() {
        println!("{}", "*".repeat(i));
    }
}

让用户自己选大小

大小作为文本从输入读进来，再用 parse 转换成数字。输入 3：

use std::io;

fn main() {
    let mut line = String::new();
    io::stdin().read_line(&mut line).unwrap();
    let n: usize = line.trim().parse().unwrap();
    for i in 1..=n {
        println!("{}", "*".repeat(i));
    }
}
*
**
***

trim() 就是陷阱所在：read_line 会把回车键的换行也一起保存（"3\n"），而这个 \n 不是数字。没有 trim() 的话，程序会停下并显示这条信息：

called `Result::unwrap()` on an `Err` value: ParseIntError { kind: InvalidDigit }

如果用户输入 hello，也是这条信息。unwrap() 的意思是“如果失败，就停止程序”；如果想提醒用户而不是停止，就对 parse 的结果使用 match。

用两个循环

repeat 是一个捷径。不用它的话，就用一个循环套另一个循环：外层遍历每一行，内层用 print! 打印星号，它不会换行。空的 println!() 在一行结束时换行。

fn main() {
    let n = 4;
    for i in 1..=n {
        for _ in 0..i {
            print!("*");
        }
        println!();
    }
}

中级：金字塔及其变体

靠右对齐

每一行先放 n - i 个空格，三角形就靠右了：

fn main() {
    let n = 5;
    for i in 1..=n {
        println!("{}{}", " ".repeat(n - i), "*".repeat(i));
    }
}

金字塔

金字塔每一行多两个星号（1、3、5、7、9），这样才有中心：2 * i - 1 个星号和 n - i 个空格。

fn main() {

空心

只画边框：第一行一个星号，最后一行是满的，中间每一行两边各一个星号，中间是 2 * i - 3 个空格。

fn main() {
    let n = 5;
    for i in 1..=n {
        if i == 1 {
            println!("{}*", " ".repeat(n - 1));
        } else if i == n {
            println!("{}", "*".repeat(2 * n - 1));
        } else {
            println!("{}*{}*", " ".repeat(n - i), " ".repeat(2 * i - 3));
        }
    }
}

用数字

每一行从 1 数到这一行的行号。map 把每个数变成文本，collect 把它们收集到一个 Vec 里，join(" ") 用空格把它们连起来：

fn main() {
    let n = 5;
    for i in 1..=n {
        let nums: Vec<String> = (1..=i).map(|j| j.to_string()).collect();
        println!("{}", nums.join(" "));
    }
}

高级：格式化、杨辉三角和谢尔宾斯基

让格式化来干活

println! 会对齐：{:>width$} 在一个宽度里靠右对齐，{:^width$} 居中。这样就不用自己算空格：

fn main() {
    let n = 5;
    for i in 1..=n {
        println!("{:>width$}", "*".repeat(i), width = n);
    }
}

减到零以下的减法

Rust 里的大小是 usize：无符号数，不能是负数。如果循环多跑了一次，n - i - 1 会试图减到零以下，程序就会停下：

fn main() {
    let n = 5;
    for i in 0..=n {
        println!("{}{}", " ".repeat(n - i - 1), "*".repeat(2 * i + 1));
    }
}

杨辉三角

每个数等于它正上方两个数之和，两边都是 1。每一行都由上一行算出来：

fn main() {
    let n = 5;
    let mut row: Vec<u64> = vec![1];
    for i in 0..n {
        let text: Vec<String> = row.iter().map(|x| x.to_string()).collect();
        println!("{}{}", " ".repeat(n - i - 1), text.join(" "));
        let mut next = vec![1];
        for k in 0..row.len() - 1 {
            next.push(row[k] + row[k + 1]);
        }
        next.push(1);
        row = next;
    }
}

  1 2 1
 1 3 3 1
1 4 6 4 1

u64 最大到 18446744073709551615。当 n 达到 68 或更大时，有一次加法就放不下了：用 rustc（或 cargo run）编译时，程序会停下并显示

attempt to add with overflow

但如果开启优化编译（-O 或 cargo run --release），这个检查会被关掉，加法会悄悄地溢出回绕：n = 70 时，最后一行中间的数是 1505813374405535736，这是错的。这么大的行要用 u128 或大整数库。

用星号画谢尔宾斯基三角形

如果在杨辉三角里只把奇数涂出来，就会出现谢尔宾斯基三角形。第 i 行第 j 个数是奇数，当且仅当 (j & i) == j：

fn main() {
    let n = 8;
    for i in 0..n {
        let row: Vec<&str> = (0..=i).map(|j| if (j & i) == j { "*" } else { " " }).collect();
        println!("{}{}", " ".repeat(n - i - 1), row.join(" "));
    }
}

在 Rust 里，和 Python 一样，& 比 == 先算，所以不加括号也能用。我们还是加上：在 JavaScript 和 C++ 里正好相反，这样代码在哪里读起来都一样。

那怎么画出来？

Rust 本身没有在窗口里画图的功能。有一些库（crate）可以做到，但对第一个程序来说，安装和配置都比较麻烦。如果你想看画出来的谢尔宾斯基三角形，可以看 JavaScript 版本，它就在浏览器里直接画出来，还有用 turtle 的 Python 版本。

我们学到了什么

三角形是一张表（每一行放多少空格、多少星号），在任何语言里都一样；而 Rust 会把隐藏的错误变成清楚的信息：让数字读不出来的换行、减到零以下的减法、放不下的加法。一开始会觉得烦，但每一条信息都是你在别的语言里要摸黑去找的错误。

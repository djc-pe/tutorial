题目 #1：SauSaGe Bank

作者 @null_djc · 系列

Codeforces 2269A · Div. 2 · 贪心、数学

简化后的题意

银行每天早上把你的余额翻倍，到了晚上你可以把全部取走： 取走的钱会加到你的卡上，账户重新变回 $1 从头开始。 银行恰好持续 n 天，而你必须恰好取款 k 天。 问题很简单：你最多能在卡上攒多少钱？

陷阱

我们首先想到的是“如果我在第 d 天取款，就能拿到 2^d”。这是个错误，因为每次取款后余额都会重置为 $1。注意如果你在第 3 天取款、第 4 天又取款会发生什么：第 4 天只翻倍了一次，所以你只拿到 $2。一次取款拿到的钱是 2 的“距上次取款的天数”次方，而不是从最开始算起。

思路

因为你必须取款 k 次， 最终你会把 n 天分成 k 个区块， 每个区块在你取款的那天结束。 如果一个区块有 g 天， 那次取款就给你 2^g。 由于 2^x 增长极快， 最好把几乎所有天数集中到一个长区块里，让其余区块尽可能短（一天，各给 $2）。

公式

答案 = 2^(n - k + 1) + 2 * (k - 1)

长区块给你留下 n - k + 1 天（靠它拿到大头），剩下的 k - 1 次取款各贡献 $2。由于 n ≤ 30，2^30 可以轻松放进 long long 里。

解答

在题目的测试用例里，这条规则没有出错：(1,1) → 2，(2,1) → 4，(4,3) → 8，(5,5) → 10，(10,2) → 514。我们把题意写成代码，用位移来实现：

C++

#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n, k;
        cin >> n >> k;

        cout << (1LL << (n - k + 1)) + 2LL * (k - 1) << '\n';
    }

    return 0;
}

Python

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    print((1 << (n - k + 1)) + 2 * (k - 1))

Rust

use std::io::{self, Read};

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();

    let mut it = input.split_whitespace();

    let t: usize = it.next().unwrap().parse().unwrap();

    for _ in 0..t {
        let n: u32 = it.next().unwrap().parse().unwrap();
        let k: i64 = it.next().unwrap().parse().unwrap();

        let answer = (1_i64 << (n - k as u32 + 1))
            + 2 * (k - 1);

        println!("{}", answer);
    }
}

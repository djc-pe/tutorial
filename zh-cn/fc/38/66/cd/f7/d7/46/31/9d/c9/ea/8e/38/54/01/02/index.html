如何用 JavaScript 打印三角形：星号、金字塔和 canvas

作者：@null_djc（系列）

  • 编程
  • JavaScript
  • 入门

星号三角形几乎是所有课程里的第一个循环练习，而在 JavaScript 里它有自己的意外：从外部来的东西永远是文本，一个不是数字的数字不会报错，运算符的先后顺序也和你想的不一样。我们先在控制台里把它做出来，最后再把它画到网页上。

我们分三个层级来讲：基础（三角形和它的陷阱）、中级（金字塔及其变体）和高级（杨辉三角、谢尔宾斯基三角形和在 canvas 上画图）。每个层级最后都有一个挑战。所有代码都可以用 Node 运行（node triangle.js），或者粘贴到浏览器的控制台里（F12）。

玩一玩三角形

读之前，先选一种类型并调整大小。下面会显示它打印出来的结果，以及实现它的 JavaScript 代码；你可以复制下来试试。

基础：三角形和它的陷阱

一个循环的三角形

第 1 行一个星号，第 2 行两个，第 3 行三个：行号和个数是同一个数。

const n = 5;
for (let i = 1; i <= n; i++) {
  console.log("*".repeat(i));
}

  • for (let i = 1; i <= n; i++) 从 1 数到 5：从 1 开始，只要 i 小于或等于 5 就继续，每次加 1。
  • "*".repeat(i) 会重复文本："*".repeat(3) 就是 "***"。
  • console.log 打印并换行。

陷阱：少了一行

出于习惯，很多 JavaScript 循环从 0 开始并用 <。在这里这样写会把三角形弄坏：

const n = 5;
for (let i = 0; i < n; i++) {
  console.log("*".repeat(i));
}

最上面多了一个空行（"*".repeat(0) 是空文本），而且少了五个星号的那一行，因为 i < n 到 4 就停了。如果结果多一行或少一行，先检查循环从哪里开始，以及条件是 < 还是 <=。

倒过来

倒置的三角形，循环要倒着数：从 n 开始，每次减 1（i--）。

const n = 5;
for (let i = n; i >= 1; i--) {
  console.log("*".repeat(i));
}

让用户自己选大小

用 Node 运行时，写在文件名后面的内容会放进 process.argv。node triangle.js 4 会打印：

const n = Number(process.argv[2]);
for (let i = 1; i <= n; i++) {
  console.log("*".repeat(i));
}

所有从外部来的东西（来自 process.argv、浏览器里的 prompt() 或表单）都是文本。所以要用 Number()。不用的话，有时碰巧能用，有时不行：

console.log("5" + 1);
console.log(Number("5") + 1);
console.log(Number("hello"));
51

NaN

"5" + 1 会把文本拼起来，得到 "51"。如果有人输入 hello，Number("hello") 得到 NaN（“不是一个数字”）：循环一次也不会执行，程序什么也不打印就结束了，也不报任何错误。要提醒用户，可以用 Number.isNaN(n) 检查。

用两个循环

repeat 是一个捷径。不用它的话，就用一个循环套另一个循环：外层遍历每一行，内层不断把星号加到一个文本里，这一行结束时再打印出来。

const n = 4;
for (let i = 1; i <= n; i++) {
  let row = "";
  for (let j = 0; j < i; j++) {
    row += "*";
  }
  console.log(row);
}

靠右对齐

每一行先放 n - i 个空格，三角形就靠右了：

金字塔

金字塔每一行多两个星号（1、3、5、7、9），这样才有中心：2 * i - 1 个星号和 n - i 个空格。

const n = 5;
for (let i = 1; i <= n; i++) {
  console.log(" ".repeat(n - i) + "*".repeat(2 * i - 1));
}

空心

只画边框：第一行一个星号，最后一行是满的，中间每一行两边各一个星号，中间是 2 * i - 3 个空格。

const n = 5;
for (let i = 1; i <= n; i++) {
  if (i === 1) {
    console.log(" ".repeat(n - 1) + "*");
  } else if (i === n) {
    console.log("*".repeat(2 * n - 1));
  } else {
    console.log(" ".repeat(n - i) + "*" + " ".repeat(2 * i - 3) + "*");
  }
}

用数字

每一行从 1 数到这一行的行号。数字放在一个数组里，join(" ") 用空格把它们连起来：

const n = 5;
for (let i = 1; i <= n; i++) {
  const nums = [];
  for (let j = 1; j <= i; j++) {
    nums.push(j);
  }
  console.log(nums.join(" "));
}

高级：杨辉三角、谢尔宾斯基和 canvas

一行代码的金字塔

Array.from 创建一个有 n 行的数组，每一行用一个函数生成；join("\n") 用换行把它们连起来。这里 k 从 0 到 4，所以星号是 2 * k + 1 个。

const n = 5;
console.log(Array.from({ length: n }, (_, k) => " ".repeat(n - k - 1) + "*".repeat(2 * k + 1)).join("\n"));

杨辉三角

每个数等于它正上方两个数之和，两边都是 1。每一行都由上一行算出来：

const n = 5;
let row = [1];
for (let i = 0; i < n; i++) {
  console.log(" ".repeat(n - i - 1) + row.join(" "));
  const next = [1];
  for (let k = 0; k < row.length - 1; k++) {
    next.push(row[k] + row[k + 1]);
  }
  next.push(1);
  row = next;
}
    1
   1 1
  1 2 1
 1 3 3 1
1 4 6 4 1

JavaScript 的数字在 Number.MAX_SAFE_INTEGER（9007199254740991）以内是精确的。当 n 达到 58 或更大时，中间的数会超过这个上限，开始被四舍五入，而且没有任何提示；这么大的行要用 BigInt。

用星号画谢尔宾斯基三角形，以及括号的陷阱

如果在杨辉三角里只把奇数涂出来，就会出现谢尔宾斯基三角形。第 i 行第 j 个数是奇数，当且仅当 (j & i) === j：

const n = 8;
for (let i = 0; i < n; i++) {
  const row = [];
  for (let j = 0; j <= i; j++) {
    row.push((j & i) === j ? "*" : " ");
  }
  console.log(" ".repeat(n - i - 1) + row.join(" "));
}

const n = 8;
for (let i = 0; i < n; i++) {
  const row = [];
  for (let j = 0; j <= i; j++) {
    row.push(j & i === j ? "*" : " ");
  }

}

在 canvas 上画出来

在浏览器里不需要打印星号：<canvas> 就是一块可以画画的区域。一个谢尔宾斯基三角形由三个边长一半的三角形组成，每一个又由三个更小的组成，一直到你指定的层级。拖动看看：

  • triangle 画一个实心三角形：用 moveTo 和 lineTo 走到每个角，闭合后用 fill() 填色。等边三角形的高是 side * √3 / 2。
  • sierpinski 用一半的边长和少一层的层级调用自己三次：左下、右下和上面。层级为 0 时画一个三角形就结束。
  • 要用在你自己的网页上，放一个 <canvas id="drawing" width="400" height="347">，在两个函数后面写 sierpinski(document.getElementById("drawing").getContext("2d"), 0, 347, 400, 5)。347 是高（400 × √3 / 2），起点是左下角。

需要注意的地方

  • 浏览器控制台会把相同的行合并。如果你连续多次打印同一行，Chrome 只显示一行，旁边带一个数字。不是你的程序有问题：在 Node 里每一行都会显示。
  • 行末的空格。如果你用 padEnd 或多余的空格拼每一行，它们看不见，但像 Codeforces 这样的评测系统会算进去。trimEnd() 可以去掉它们。
  • 要写 let 或 const，不能什么都不写。没有 let 的 for (i = 1; ...) 会创建一个全局变量，在模块或严格模式下会报 ReferenceError: i is not defined。

我们学到了什么

三角形是一张表（每一行放多少空格、多少星号），在任何语言里都一样；而在 JavaScript 里最容易出错的不是公式，而是公式周围的东西：从外部来的文本、本该是 <= 的 <，以及比你想的更早被计算的运算符。好消息是浏览器自带画图的地方：拖动 canvas 的层级，看看同一个图案怎样在自己里面重复。

入门

从零开始的教程：一步一步讲解，不预设任何基础，并配有练习。

如何用 JavaScript 打印三角形：星号、金字塔和 canvas

从星号三角形到杨辉三角和谢尔宾斯基三角形，讲清文本和括号的陷阱，还能在 canvas 上画出来。

如何用 Rust 打印三角形：星号、金字塔和谢尔宾斯基

从星号三角形到杨辉三角和谢尔宾斯基三角形，讲解范围、parse、usize 和编译器的错误信息。

如何用 C++ 打印三角形：星号、金字塔和谢尔宾斯基

从星号三角形到杨辉三角和谢尔宾斯基三角形，讲解 cin、std::string 和括号这些不出声的错误。

如何用 Python 打印三角形：星号、金字塔和 turtle

从星号三角形到金字塔、杨辉三角和谢尔宾斯基三角形，附常见错误和用 turtle 画图。

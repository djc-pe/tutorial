如何用 Python 打印三角形：星号、金字塔和 turtle

作者：@null_djc（系列）

  • Python
  • 编程
  • 入门

如果你正在学编程，迟早会遇到这道题：“用星号打印一个三角形”。看起来像个游戏，但它正是逼你真正理解循环的练习：循环跑几次、每一次变的是什么，以及为什么总像是少了一行。我们花的时间比想象中多，而且几乎每次都错在同一个数字上。

我们分三个层级来讲：基础（三角形和它的陷阱）、中级（金字塔及其变体）和高级（杨辉三角、谢尔宾斯基三角形和用 turtle 画图）。每个层级最后都有一个挑战。

玩一玩三角形

读之前，先选一种类型并调整大小。下面会显示它打印出来的结果，以及实现它的 Python 代码；你可以复制下来在自己的电脑上试试。

基础：三角形和它的陷阱

三行代码的三角形

思路很简单：第 1 行一个星号，第 2 行两个，第 3 行三个。行号和星号的个数是同一个数。

n = 5
for i in range(1, n + 1):
    print("*" * i)
*
**
***
****
*****
  • range(1, n + 1) 给出 1 到 5：从第一个数开始，在第二个数之前停下。所以要写 n + 1。
  • "*" * i 会重复文本："*" * 3 就是 "***"。Python 允许用文本乘以数字，这样就省掉了一个循环。

陷阱：少了一行

我们最开始写的是这样，结果三角形不对：

n = 5
for i in range(n):
    print("*" * i)

*
**
***
****

最上面多了一个空行，最下面少了五个星号的那一行。range(n) 是从 0 到 4：第一次循环打印 "*" * 0，也就是空文本，而且永远到不了 5。这是这道题最常见的错误，在其他语言里也一样：如果结果多一行或少一行，先检查循环从哪里开始、到哪里结束。

倒过来

倒置的三角形，循环要倒着数：range(n, 0, -1) 从 5 数到 1（第三个数是步长）。

n = 5
for i in range(n, 0, -1):
    print("*" * i)
*****
****
***
**
*

让用户自己选大小

n = int(input("Size: "))
for i in range(1, n + 1):
    print("*" * i)

input() 返回的永远是文本，就算你输入的是数字。如果忘了 int()，Python 会在 range 那里报错：

TypeError: can only concatenate str (not "int") to str

如果用户输入的不是数字，比如 hello，出错的就是 int()：

ValueError: invalid literal for int() with base 10: 'hello'

用两个循环

文本相乘是 Python 的捷径。很多语言没有这个功能，要用一个循环套另一个循环：外层循环遍历每一行，内层循环打印这一行的星号。

n = 3
for i in range(1, n + 1):
    for j in range(i):
        print("*", end="")
    print()
*
**
***

end="" 让 print 在每个星号之后不换行，空的 print() 在一行结束时换行。之后我们用其他语言写同样的三角形时，看到的就是这种写法。

中级：金字塔及其变体

靠右对齐

要把三角形推到右边，每一行都先打印空格。第 1 行离五个星号还差四个，所以放四个空格；最后一行一个也不用：n - i 个空格。

n = 5
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * i)

金字塔

金字塔每一行多两个星号（1、3、5、7、9），这样才有中心。这个数就是 2 * i - 1，空格仍然是 n - i：

n = 5
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))

空心

空心金字塔只画边框。第一行一个星号，最后一行是满的，中间每一行两边各一个星号，中间是空格（同样是 2 * i - 1 个位置，减去两边）：

n = 5
for i in range(1, n + 1):
    if i == 1:
        print(" " * (n - 1) + "*")
    elif i == n:
        print("*" * (2 * n - 1))
    else:
        print(" " * (n - i) + "*" + " " * (2 * i - 3) + "*")

用数字

不用星号，每一行从 1 数到这一行的行号。str(j) 把数字变成文本，" ".join(...) 用空格把它们连起来：

n = 5
for i in range(1, n + 1):
    print(" ".join(str(j) for j in range(1, i + 1)))

高级：杨辉三角、谢尔宾斯基和 turtle

一行代码的金字塔

center() 会把文本放在给定宽度的正中间，所以不用自己算空格：

n = 5
print("\n".join(("*" * (2 * i - 1)).center(2 * n - 1).rstrip() for i in range(1, n + 1)))
    *
   ***
  *****
 *******
*********

center() 在右边也会补空格。看不见，但确实存在，像 Codeforces 这样的评测系统可能会因此判你答案错误。rstrip() 可以把它们去掉。

杨辉三角

每个数等于它正上方两个数之和，两边都是 1。每一行都由上一行算出来：

n = 5
row = [1]
for i in range(n):
    print(" " * (n - i - 1) + " ".join(str(x) for x in row))
    row = [1] + [row[k] + row[k + 1] for k in range(len(row) - 1)] + [1]
    1
   1 1
  1 2 1
 1 3 3 1
1 4 6 4 1

n 变大以后，两位数和三位数会让图形对不齐。要想好看，就给每个数相同的宽度（比如用 str(x).center(4)）。

用星号画谢尔宾斯基三角形

如果在杨辉三角里只把奇数涂出来，就会出现一个由三角形组成的三角形：谢尔宾斯基三角形。有一个不用计算就能判断杨辉三角里某个数是不是奇数的方法：第 i 行第 j 个数是奇数，当且仅当 (j & i) == j，也就是 j 的二进制位都包含在 i 里。

n = 8
for i in range(n):
    row = ["*" if (j & i) == j else " " for j in range(i + 1)]
    print(" " * (n - i - 1) + " ".join(row))
       *
      * *
     *   *
    * * * *
   *       *
  * *     * *
 *   *   *   *
* * * * * * * *

当 n 等于 4、8、16 或 32 时，图形是完整的。在 Python 里 (j & i) == j 的括号不是必须的，因为 & 比 == 先算；但在 JavaScript 或 C++ 这些语言里正好相反：不加括号，结果就变了。

用 turtle 画出来

Python 自带 turtle，一只边走边在窗口里画画的小海龟。画等边三角形就是：前进、转 120 度，重复三次：

import turtle

t = turtle.Turtle()
for _ in range(3):
    t.forward(200)
    t.left(120)

turtle.done()

为什么是 120 而不是 60？三角形的内角是 60 度，但海龟转的是朝向新方向所需要的角度，也就是 180 − 60 = 120。三次转弯加起来是 360 度：海龟最后又面朝出发时的方向。

再用海龟画谢尔宾斯基三角形：一个三角形由三个边长一半的三角形组成，每一个又由三个更小的组成，一直到你指定的层级。这就是递归：函数用少一层的参数调用自己。

import turtle


def sierpinski(t, side, level):
    if level == 0:
        for _ in range(3):
            t.forward(side)
            t.left(120)
        return
    half = side / 2
    sierpinski(t, half, level - 1)                # bottom left
    t.forward(half)
    sierpinski(t, half, level - 1)                # bottom right
    t.backward(half)
    t.left(60)
    t.forward(half)
    t.right(60)
    sierpinski(t, half, level - 1)                # top
    t.left(60)
    t.backward(half)
    t.right(60)


t = turtle.Turtle()
t.speed(0)
t.penup()
t.goto(-200, -170)
t.pendown()
sierpinski(t, 400, 4)
turtle.done()
  • 每次调用都会画出三个小三角形（左下、右下和上面），并把海龟带回出发时的位置和方向。正因为这样，它才能一直重复下去。
  • 层级为 4 时会画出 81 个三角形（3 × 3 × 3 × 3）。t.speed(0) 是最快的速度。

需要注意的地方

  • 如果看到 ModuleNotFoundError: No module named 'tkinter'，说明你的 Python 缺少打开窗口的那部分。在 Ubuntu 或 Debian 上用 sudo apt install python3-tk 安装；在 Windows 和 macOS 上，python.org 的安装包已经自带了。
  • turtle 需要一个窗口。在 Google Colab 这样的在线笔记本里用不了；星号三角形可以。
  • 缩进很重要。如果 print 没有缩进到 for 里面，Python 会提示 IndentationError: expected an indented block after 'for' statement。

我们学到了什么

星号三角形其实不是一幅画，而是一张表：每一行放多少个空格、多少个星号。把它手写出来，公式自己就出来了，而几乎所有错误都是 range 里多了一个或少了一个数。从这里可以走到金字塔、杨辉三角，再加上一点位运算，就到了谢尔宾斯基三角形。在上面的工具里把 n 设成 16 再选谢尔宾斯基试试：还是那个熟悉的循环。

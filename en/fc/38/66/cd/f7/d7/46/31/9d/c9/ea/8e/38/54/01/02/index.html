How to Make a Triangle in JavaScript: Asterisks, Pyramid and Canvas

Series by @null_djc

  • Programming
  • JavaScript
  • Beginners

The asterisk triangle is the first loop exercise in almost any course, and in JavaScript it has its own surprises: whatever comes from outside is always text, a number that is not a number does not throw an error and the order of operators is not the one you expect. We build it in the console and, at the end, we draw it on the page.

We cover it in three levels: basic (the triangle and its traps), intermediate (the pyramid and its variants) and advanced (Pascal, Sierpinski and drawing on a canvas). Each level ends with a challenge. Everything runs with Node (node triangle.js) or pasted into the browser console (F12).

Play with the triangle

Before reading, pick a type and move the size. Below you see what it prints and the JavaScript code that does it; you can copy it and try it.

Basic: the triangle and its traps

The triangle with one loop

Row 1 has one asterisk, row 2 has two, row 3 has three: the row and the count are the same number.

const n = 5;
for (let i = 1; i <= n; i++) {
  console.log("*".repeat(i));
}
*

***

*****
  • for (let i = 1; i <= n; i++) counts from 1 to 5: it starts at 1, keeps going while i is less than or equal to 5 and adds 1 on each pass.
  • "*".repeat(i) repeats the text: "*".repeat(3) is "***".
  • console.log prints and jumps to a new line.

The trap: the missing row

Out of habit, many JavaScript loops start at 0 and use <. Here that breaks the triangle:

const n = 5;
for (let i = 0; i < n; i++) {
  console.log("*".repeat(i));
}

***
****

There is an empty line at the top ("*".repeat(0) is empty text) and the row of five is missing, because i < n stops at 4. When the result has one row too many or too few, first check where the loop starts and whether the condition is < or <=.

Upside down

For the inverted triangle, the loop counts backwards: it starts at n and subtracts 1 (i--).

const n = 5;
for (let i = n; i >= 1; i--) {
  console.log("*".repeat(i));
}

Let the user choose the size

With Node, whatever you type after the file name arrives in process.argv. node triangle.js 4 prints:

  console.log("*".repeat(i));

Everything that comes from outside (from process.argv, from prompt() in the browser or from a form) is text. That is why there is a Number(). Without it, sometimes it works by luck and sometimes it does not:

console.log("5" + 1);
console.log(Number("5") + 1);
console.log(Number("hello"));
51
6
NaN

"5" + 1 sticks the texts together and gives "51". And if someone types hello, Number("hello") gives NaN ("not a number"): the loop does not run even once and the program ends without printing anything and without any error. To warn the user, check with Number.isNaN(n).

With two loops

repeat is a shortcut. Without it, the row is built with a loop inside another: the outer one goes through the rows and the inner one keeps adding asterisks to a text, which is printed at the end of the row.

const n = 4;
for (let i = 1; i <= n; i++) {
  let row = "";
  for (let j = 0; j < i; j++) {
    row += "*";
  }
  console.log(row);
}

In JavaScript console.log always jumps to a new line, so the whole row is built before printing it.

Intermediate: the pyramid and its variants

Right-aligned

Each row starts with n - i spaces, so the triangle sits against the right:

The pyramid

The pyramid grows by two asterisks per row (1, 3, 5, 7, 9) so it has a center: 2 * i - 1 asterisks and n - i spaces.

This table is the trick for any pattern: write down by hand how much goes in each row and look for the formula. If the pyramid comes out crooked, the spaces are almost always n - i - 1 or the asterisks 2 * i.

Hollow

Only the border: the first row with one asterisk, the last one full and the middle ones with an asterisk on each side and 2 * i - 3 spaces in the center.

const n = 5;
for (let i = 1; i <= n; i++) {
  if (i === 1) {
    console.log(" ".repeat(n - 1) + "*");
  } else if (i === n) {
    console.log("*".repeat(2 * n - 1));
  } else {
    console.log(" ".repeat(n - i) + "*" + " ".repeat(2 * i - 3) + "*");
  }
}

Note the ===: in JavaScript it compares without converting types. With ==, "1" == 1 gives true, and that hides exactly the mistake of the text that comes from outside.

With numbers

Each row counts from 1 to the row number. The numbers are stored in an array and join(" ") joins them with spaces:

const n = 5;
for (let i = 1; i <= n; i++) {
  const nums = [];
  for (let j = 1; j <= i; j++) {
    nums.push(j);
  }
  console.log(nums.join(" "));
}

Advanced: Pascal, Sierpinski and canvas

The pyramid in one line

Array.from creates an array of n rows and builds each one with a function; join("\n") joins them with line breaks. Here k goes from 0 to 4, so the asterisks are 2 * k + 1.

const n = 5;
console.log(Array.from({ length: n }, (_, k) => " ".repeat(n - k - 1) + "*".repeat(2 * k + 1)).join("\n"));

Pascal's triangle

Each number is the sum of the two on top of it, and the borders are 1. Each row is built from the previous one:

const n = 5;
let row = [1];
for (let i = 0; i < n; i++) {
  console.log(" ".repeat(n - i - 1) + row.join(" "));
  const next = [1];
  for (let k = 0; k < row.length - 1; k++) {
    next.push(row[k] + row[k + 1]);
  }
  next.push(1);
  row = next;
}
    1
   1 1
  1 2 1
 1 3 3 1
1 4 6 4 1

JavaScript numbers are exact up to Number.MAX_SAFE_INTEGER (9007199254740991). With n of 58 or more, the numbers in the center go past that limit and start coming out rounded, without any warning; for rows that big you use BigInt.

Sierpinski with asterisks, and the parentheses trap

If you only paint the odd numbers of Pascal's triangle, the Sierpinski triangle appears. The number in row i and position j is odd when (j & i) === j:

const n = 8;
for (let i = 0; i < n; i++) {
  const row = [];
  for (let j = 0; j <= i; j++) {
    row.push((j & i) === j ? "*" : " ");
  }
  console.log(" ".repeat(n - i - 1) + row.join(" "));
}

In Python those parentheses are not needed. In JavaScript they are: === is evaluated before &. Without parentheses, j & i === j is j & (i === j), and the drawing breaks without any error:

const n = 8;
for (let i = 0; i < n; i++) {
  const row = [];
  for (let j = 0; j <= i; j++) {
    row.push(j & i === j ? "*" : " ");
  }
  console.log(" ".repeat(n - i - 1) + row.join(" "));
}

Draw it on a canvas

In the browser there is no need to print asterisks: a <canvas> is a surface you draw on. A Sierpinski triangle is made of three half its size, and each of those of three more, down to the level you ask for. Move it:

  • triangle draws a filled one: it goes to each corner with moveTo and lineTo, closes it and paints it with fill(). The height of an equilateral triangle is side * √3 / 2.
  • sierpinski calls itself with half the side and one level less, three times: bottom left, bottom right and top. At level 0 it draws a triangle and stops.
  • To use it on your page, add a <canvas id="drawing" width="400" height="347"> and, after the two functions, sierpinski(document.getElementById("drawing").getContext("2d"), 0, 347, 400, 5). The 347 is the height (400 × √3 / 2) and the starting point is the bottom left corner.

What to watch out for

  • The browser console groups identical lines. If you print the same row several times in a row, Chrome shows a single one with a number next to it. It is not your program: in Node they all show up.
  • Trailing spaces. If you build each row with padEnd or with extra spaces, you cannot see them, but a judge like Codeforces' counts them. trimEnd() removes them.
  • let or const, never nothing. A for (i = 1; ...) without let creates a global variable and, in a module or in strict mode, gives ReferenceError: i is not defined.

What it taught us

That the triangle is a table (how many spaces and how many asterisks in each row), just like in any language, and that in JavaScript what breaks most is not the formula but what surrounds it: the text that comes from outside, the < that should be <= and an operator that is evaluated earlier than you expected. The good news is that the browser already has a place to draw it: move the canvas level and watch the same pattern repeat inside itself.

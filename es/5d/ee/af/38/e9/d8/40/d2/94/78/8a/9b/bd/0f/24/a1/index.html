Cómo hacer un triángulo en Rust: asteriscos, pirámide y Sierpinski

Serie por @null_djc

  • Rust
  • Programación
  • Principiantes

El triángulo de asteriscos es el primer ejercicio de bucles de casi cualquier curso. En Rust se escribe parecido a Python, pero el compilador te cuida de cosas que en otros lenguajes pasan en silencio: un número que no se puede leer, una resta que se pasa de cero o una suma que no cabe. Aquí vemos esas trampas con sus mensajes reales.

Lo vemos en tres niveles: básico (el triángulo y sus trampas), intermedio (la pirámide y sus variantes) y avanzado (formatos, Pascal y Sierpinski). Cada nivel termina con un reto. Para probar el código: rustc triangulo.rs && ./triangulo, cargo run dentro de un proyecto, o el Rust Playground en el navegador.

Juega con el triángulo

Antes de leer, elige un tipo y mueve el tamaño. Abajo ves lo que imprime y el código en Rust que lo hace; puedes copiarlo y probarlo.

Básico: el triángulo y sus trampas

El triángulo con un bucle

En la fila 1 va un asterisco, en la 2 van dos, en la 3 van tres: la fila y la cantidad son el mismo número.

fn main() {
    let n = 5;
    for i in 1..=n {
        println!("{}", "*".repeat(i));
    }
}

  • 1..=n es el rango del 1 al 5, incluido el 5 (por el =).
  • "*".repeat(i) repite el texto: "*".repeat(3) es "***".
  • println! imprime y salta de línea; el {} es el lugar donde va el valor.

La trampa: la fila que falta

En Rust hay dos rangos que se parecen mucho: 0..n no incluye el último y 0..=n sí. Con el primero, el triángulo sale mal:

fn main() {
    let n = 5;
    for i in 0..n {
        println!("{}", "*".repeat(i));
    }
}

Arriba sale una línea vacía ("*".repeat(0) es un texto vacío) y falta la fila de cinco. Cuando el resultado tiene una fila de más o de menos, revisa primero el rango: dónde empieza y si lleva =.

Al revés

Para el triángulo invertido, el rango se recorre al revés con .rev():

fn main() {
    let n = 5;
    for i in (1..=n).rev() {
        println!("{}", "*".repeat(i));
    }
}

Que el usuario elija el tamaño

El tamaño se lee de la entrada como texto y se convierte en número con parse. Escribiendo 3:

use std::io;

fn main() {
    let mut linea = String::new();
    io::stdin().read_line(&mut linea).unwrap();
    let n: usize = linea.trim().parse().unwrap();
    for i in 1..=n {
        println!("{}", "*".repeat(i));
    }
}
*
**
***

El trim() es la trampa: read_line guarda también el salto de línea del Enter ("3\n"), y ese \n no es un dígito. Sin trim(), el programa se detiene con este mensaje:

called `Result::unwrap()` on an `Err` value: ParseIntError { kind: InvalidDigit }

Es el mismo mensaje que si el usuario escribe hola. El unwrap() dice "si falla, detén el programa"; para avisarle al usuario en vez de detenerlo, se usa match sobre el resultado de parse.

Con dos bucles

repeat es un atajo. Sin él, se usa un bucle dentro de otro: el de afuera recorre las filas y el de adentro imprime los asteriscos con print!, que no salta de línea. El println!() vacío salta al terminar la fila.

fn main() {
    let n = 4;
    for i in 1..=n {
        for _ in 0..i {
            print!("*");
        }
        println!();
    }
}

Intermedio: la pirámide y sus variantes

Alineado a la derecha

Cada fila empieza con n - i espacios, así el triángulo queda pegado a la derecha:

fn main() {
    let n = 5;
    for i in 1..=n {
        println!("{}{}", " ".repeat(n - i), "*".repeat(i));
    }
}

La pirámide

La pirámide crece de a dos asteriscos por fila (1, 3, 5, 7, 9) para que quede un centro: 2 * i - 1 asteriscos y n - i espacios.

fn main() {
    let n = 5;
    for i in 1..=n {
        println!("{}{}", " ".repeat(n - i), "*".repeat(2 * i - 1));
    }
}

Hueca

Solo el borde: la primera fila con un asterisco, la última llena y las del medio con un asterisco a cada lado y 2 * i - 3 espacios en el centro.

fn main() {
    let n = 5;
    for i in 1..=n {
        if i == 1 {
            println!("{}*", " ".repeat(n - 1));
        } else if i == n {
            println!("{}", "*".repeat(2 * n - 1));
        } else {
            println!("{}*{}*", " ".repeat(n - i), " ".repeat(2 * i - 3));
        }
    }
}

Con números

Cada fila cuenta del 1 al número de la fila. map convierte cada número en texto, collect los junta en un Vec y join(" ") los une con espacios:

fn main() {
    let n = 5;
    for i in 1..=n {
        let nums: Vec<String> = (1..=i).map(|j| j.to_string()).collect();
        println!("{}", nums.join(" "));
    }
}

Avanzado: formatos, Pascal y Sierpinski

Que el formato haga el trabajo

println! sabe alinear: {:>width$} alinea a la derecha en un ancho y {:^ancho$} centra. Así no hay que calcular espacios:

fn main() {
    let n = 5;
    for i in 1..=n {
        println!("{:>width$}", "*".repeat(i), width = n);
    }
}

La resta que se pasa de cero

Los tamaños en Rust son usize: números sin signo, que no pueden ser negativos. Si el bucle da una vuelta de más, n - i - 1 intenta bajar de cero y el programa se detiene:

fn main() {
    let n = 5;
    for i in 0..=n {
        println!("{}{}", " ".repeat(n - i - 1), "*".repeat(2 * i + 1));
    }
}

En otros lenguajes esa resta daría un número negativo y el error pasaría escondido. Aquí el mensaje dice exactamente qué pasó: el rango tenía que ser 0..n.

El triángulo de Pascal

Cada número es la suma de los dos que tiene encima, y los bordes son 1. Cada fila se arma a partir de la anterior:

fn main() {
    let n = 5;
    let mut fila: Vec<u64> = vec![1];
    for i in 0..n {
        let texto: Vec<String> = fila.iter().map(|x| x.to_string()).collect();
        println!("{}{}", " ".repeat(n - i - 1), texto.join(" "));
        let mut nueva = vec![1];
        for k in 0..fila.len() - 1 {
            nueva.push(fila[k] + fila[k + 1]);
        }
        nueva.push(1);
        fila = nueva;
    }
}

1 4 6 4 1

Un u64 llega hasta 18446744073709551615. Con n de 68 o más, una de las sumas ya no cabe: con rustc (o cargo run) el programa se detiene con

attempt to add with overflow

pero compilado con optimizaciones (-O o cargo run --release) esa revisión se apaga y la suma da la vuelta en silencio: con n = 70, el número del centro de la última fila sale 1505813374405535736, que está mal. Para filas tan grandes se usa u128 o una librería de enteros grandes.

Sierpinski con asteriscos

Si en el triángulo de Pascal pintas solo los números impares, aparece el triángulo de Sierpinski. El de la fila i y la posición j es impar cuando (j & i) == j:

fn main() {
    let n = 8;
    for i in 0..n {
        let fila: Vec<&str> = (0..=i).map(|j| if (j & i) == j { "*" } else { " " }).collect();
        println!("{}{}", " ".repeat(n - i - 1), fila.join(" "));
    }
}

En Rust, como en Python, & se calcula antes que ==, así que funcionaría sin paréntesis. Los dejamos igual: en JavaScript y en C++ es al revés, y así el código se lee igual en todos lados.

¿Y para dibujarlo?

Rust no trae nada para dibujar en una ventana. Hay librerías (crates) para eso, pero piden instalar y configurar bastante para un primer programa. Si quieres ver el Sierpinski dibujado, tienes la versión en JavaScript, que se dibuja aquí mismo en el navegador, y la de Python con turtle.

Qué nos enseñó

Que el triángulo es una tabla (cuántos espacios y cuántos asteriscos en cada fila), igual que en cualquier lenguaje, y que Rust convierte los errores escondidos en mensajes claros: el salto de línea que no deja leer el número, la resta que baja de cero, la suma que no cabe. Molesta al principio, pero cada uno de esos mensajes es un error que en otro lenguaje habrías buscado a ciegas.

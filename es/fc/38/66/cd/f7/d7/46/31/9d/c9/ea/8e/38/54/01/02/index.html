Cómo hacer un triángulo en JavaScript: asteriscos, pirámide y canvas

Serie por @null_djc

  • JavaScript
  • Programación
  • Principiantes

El triángulo de asteriscos es el primer ejercicio de bucles en casi cualquier curso, y en JavaScript tiene sus propias sorpresas: lo que llega de afuera siempre es texto, un número que no es número no da error y el orden de los operadores no es el que esperas. Lo armamos en la consola y, al final, lo dibujamos en la página.

Lo vemos en tres niveles: básico (el triángulo y sus trampas), intermedio (la pirámide y sus variantes) y avanzado (Pascal, Sierpinski y el dibujo en un canvas). Cada nivel termina con un reto. Todo se puede correr con Node (node triangulo.js) o pegándolo en la consola del navegador (F12).

Juega con el triángulo

Antes de leer, elige un tipo y mueve el tamaño. Abajo ves lo que imprime y el código en JavaScript que lo hace; puedes copiarlo y probarlo.

Básico: el triángulo y sus trampas

El triángulo con un bucle

En la fila 1 va un asterisco, en la 2 van dos, en la 3 van tres: la fila y la cantidad son el mismo número.

const n = 5;
for (let i = 1; i <= n; i++) {
  console.log("*".repeat(i));
}

  • for (let i = 1; i <= n; i++) cuenta del 1 al 5: empieza en 1, sigue mientras i sea menor o igual a 5 y suma 1 en cada vuelta.
  • "*".repeat(i) repite el texto: "*".repeat(3) es "***".
  • console.log imprime y salta de línea.

La trampa: la fila que falta

Muchos bucles en JavaScript se escriben desde 0 y con <, por costumbre. Aquí eso rompe el triángulo:

const n = 5;
for (let i = 0; i < n; i++) {
  console.log("*".repeat(i));
}

Arriba sale una línea vacía ("*".repeat(0) es un texto vacío) y falta la fila de cinco, porque i < n se detiene en 4. Cuando el resultado tiene una fila de más o de menos, revisa primero dónde empieza el bucle y si la condición es < o <=.

Al revés

Para el triángulo invertido, el bucle cuenta hacia atrás: empieza en n y resta 1 (i--).

const n = 5;
for (let i = n; i >= 1; i--) {
  console.log("*".repeat(i));
}

Que el usuario elija el tamaño

Con Node, lo que escribes después del nombre del archivo llega en process.argv. node triangulo.js 4 imprime:

Todo lo que llega de afuera (de process.argv, de prompt() en el navegador o de un formulario) es texto. Por eso va Number(). Sin él, a veces funciona por suerte y a veces no:

console.log("5" + 1);
console.log(Number("5") + 1);
console.log(Number("hola"));

"5" + 1 pega los textos y da "51". Y si alguien escribe hola, Number("hola") da NaN ("no es un número"): el bucle no da ni una vuelta y el programa termina sin imprimir nada y sin ningún error. Para avisarle al usuario, revisa con Number.isNaN(n).

Con dos bucles

repeat es un atajo. Sin él, la fila se arma con un bucle dentro de otro: el de afuera recorre las filas y el de adentro va sumando asteriscos a un texto, que se imprime al final de la fila.

const n = 4;
for (let i = 1; i <= n; i++) {
  let fila = "";
  for (let j = 0; j < i; j++) {
    fila += "*";
  }
  console.log(fila);
}

En JavaScript console.log siempre salta de línea, así que la fila se arma completa antes de imprimirla.

Intermedio: la pirámide y sus variantes

Alineado a la derecha

Cada fila empieza con n - i espacios, así el triángulo queda pegado a la derecha:

for (let i = 1; i <= n; i++) {
  console.log(" ".repeat(n - i) + "*".repeat(i));

La pirámide

La pirámide crece de a dos asteriscos por fila (1, 3, 5, 7, 9) para que quede un centro: 2 * i - 1 asteriscos y n - i espacios.

const n = 5;
for (let i = 1; i <= n; i++) {
  console.log(" ".repeat(n - i) + "*".repeat(2 * i - 1));
}

Hueca

Solo el borde: la primera fila con un asterisco, la última llena y las del medio con un asterisco a cada lado y 2 * i - 3 espacios en el centro.

const n = 5;
for (let i = 1; i <= n; i++) {
  if (i === 1) {
    console.log(" ".repeat(n - 1) + "*");
  } else if (i === n) {
    console.log("*".repeat(2 * n - 1));
  } else {
    console.log(" ".repeat(n - i) + "*" + " ".repeat(2 * i - 3) + "*");
  }
}

Fíjate en el ===: en JavaScript compara sin convertir tipos. Con ==, "1" == 1 da true, y eso esconde justo el error del texto que llega de afuera.

Con números

Cada fila cuenta del 1 al número de la fila. Los números se guardan en un arreglo y join(" ") los une con espacios:

const n = 5;
for (let i = 1; i <= n; i++) {
  const nums = [];
  for (let j = 1; j <= i; j++) {
    nums.push(j);
  }
  console.log(nums.join(" "));
}

Avanzado: Pascal, Sierpinski y canvas

La pirámide en una línea

Array.from crea un arreglo de n filas y arma cada una con una función; join("\n") las une con saltos de línea. Aquí k va del 0 al 4, por eso los asteriscos son 2 * k + 1.

const n = 5;
console.log(Array.from({ length: n }, (_, k) => " ".repeat(n - k - 1) + "*".repeat(2 * k + 1)).join("\n"));

El triángulo de Pascal

Cada número es la suma de los dos que tiene encima, y los bordes son 1. Cada fila se arma a partir de la anterior:

const n = 5;
let fila = [1];
for (let i = 0; i < n; i++) {
  console.log(" ".repeat(n - i - 1) + fila.join(" "));
  const nueva = [1];
  for (let k = 0; k < fila.length - 1; k++) {
    nueva.push(fila[k] + fila[k + 1]);
  }
  nueva.push(1);
  fila = nueva;
}

Los números de JavaScript son exactos hasta Number.MAX_SAFE_INTEGER (9007199254740991). Con n de 58 o más, los números del centro pasan de ese límite y empiezan a salir redondeados, sin ningún aviso; para filas tan grandes se usa BigInt.

Sierpinski con asteriscos, y la trampa de los paréntesis

Si en el triángulo de Pascal pintas solo los números impares, aparece el triángulo de Sierpinski. El número de la fila i y la posición j es impar cuando (j & i) === j:

const n = 8;
for (let i = 0; i < n; i++) {
  const fila = [];
  for (let j = 0; j <= i; j++) {
    fila.push((j & i) === j ? "*" : " ");
  }
  console.log(" ".repeat(n - i - 1) + fila.join(" "));
}

En Python esos paréntesis no hacen falta. En JavaScript sí: === se calcula antes que &. Sin paréntesis, j & i === j es j & (i === j), y el dibujo se rompe sin ningún error:

const n = 8;
for (let i = 0; i < n; i++) {
  const fila = [];
  for (let j = 0; j <= i; j++) {
    fila.push(j & i === j ? "*" : " ");
  }
  console.log(" ".repeat(n - i - 1) + fila.join(" "));
}

Dibujarlo en un canvas

En el navegador no hace falta imprimir asteriscos: un <canvas> es una superficie donde se dibuja. Un triángulo de Sierpinski se arma con tres de la mitad de tamaño, y cada uno de esos con tres más, hasta el nivel que pidas. Muévelo:

  • triangulo dibuja uno relleno: va a cada esquina con moveTo y lineTo, lo cierra y lo pinta con fill(). El alto de un triángulo equilátero es lado * √3 / 2.
  • sierpinski se llama a sí misma con la mitad del lado y un nivel menos, tres veces: abajo a la izquierda, abajo a la derecha y arriba. Con nivel 0 dibuja un triángulo y termina.
  • Para usarlo en tu página, pones un <canvas id="dibujo" width="400" height="347"> y, después de las dos funciones, sierpinski(document.getElementById("dibujo").getContext("2d"), 0, 347, 400, 5). El 347 es el alto (400 × √3 / 2) y el punto de partida es la esquina de abajo a la izquierda.

Lo que hay que mirar con cuidado

  • La consola del navegador junta las líneas iguales. Si imprimes la misma fila varias veces seguidas, Chrome muestra una sola con un número al lado. No es tu programa: en Node salen todas.
  • Espacios al final. Si armas cada fila con padEnd o con espacios de más, no se ven, pero un juez como el de Codeforces los cuenta. trimEnd() los quita.
  • let o const, nunca sin nada. Un for (i = 1; ...) sin let crea una variable global y, en un módulo o en modo estricto, da ReferenceError: i is not defined.

Qué nos enseñó

Que el triángulo es una tabla (cuántos espacios y cuántos asteriscos en cada fila), igual que en cualquier lenguaje, y que en JavaScript lo que más se rompe no es la fórmula sino lo que la rodea: el texto que llega de afuera, el < que debería ser <= y un operador que se calcula antes de lo que esperabas. Lo bueno es que el navegador ya trae dónde dibujarlo: mueve el nivel del canvas y mira cómo el mismo patrón se repite dentro de sí mismo.

Problema #1: SauSaGe Bank

Por @null_djc · Serie

Codeforces 2269A · Div. 2 · greedy, math

El enunciado simplificado

Un banco duplica tu saldo cada mañana y a la noche puedes retirar todo: lo que retirás se suma a tu tarjeta y tu cuenta vuelve a $1 para empezar de nuevo. El banco dura exactamente n días y tienes que retirar exactamente k días. La pregunta es simple: ¿cuánto es lo máximo que puedes juntar en la tarjeta?

La trampa

Lo primero que pensamos fue "si retiro el día d, cobro 2^d". Y es un error, porque después de cada retiro el saldo se reinicia a $1. Fijate qué pasa si retirás el día 3 y otra vez el día 4: el día 4 recién hubo un duplicado, así que cobrás solo $2. Lo que cobrás en un retiro es 2 elevado a la cantidad de días desde el último retiro, no desde el día inicial.

La idea

Como tienes que retirar k veces, terminás partiendo los n días en k bloques, y cada bloque termina el día en que retirás. Si un bloque tiene g días, ese retiro te da 2^g. Como 2^x crece rapidísimo, conviene concentrar casi todo en un solo bloque largo y que los demás sean lo más corto posible (un día, que da $2 cada uno).

La fórmula

respuesta = 2^(n - k + 1) + 2 * (k - 1)

El bloque largo te deja n - k + 1 días (y con eso ganás la parte gorda), y los k - 1 retiros restantes aportan $2 cada uno. Como n ≤ 30, 2^30 entra cómodo en un long long.

La solución

En los casos de prueba del problema, la regla no falla: (1,1) → 2, (2,1) → 4, (4,3) → 8, (5,5) → 10, (10,2) → 514. Convertimos el enunciado a código, con un corrimiento de bits:

C++

#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n, k;
        cin >> n >> k;

        cout << (1LL << (n - k + 1)) + 2LL * (k - 1) << '\n';
    }

    return 0;
}

Python

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    print((1 << (n - k + 1)) + 2 * (k - 1))

Rust

use std::io::{self, Read};

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();

    let mut it = input.split_whitespace();

    let t: usize = it.next().unwrap().parse().unwrap();

    for _ in 0..t {
        let n: u32 = it.next().unwrap().parse().unwrap();
        let k: i64 = it.next().unwrap().parse().unwrap();

        let answer = (1_i64 << (n - k as u32 + 1))
            + 2 * (k - 1);

        println!("{}", answer);
    }
}

Qué nos enseñó

A leer con cuidado el efecto de cada evento y en qué orden pasan: el "reseteo" del saldo era todo el problema. Y a jugar con los ejemplos a mano antes de abrir el editor, porque ahí apareció el patrón que después se volvió fórmula.

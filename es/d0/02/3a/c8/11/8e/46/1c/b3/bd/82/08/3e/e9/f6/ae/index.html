Cómo hacer un triángulo en C++: asteriscos, pirámide y Sierpinski

Serie por @null_djc

  • Programación
  • C++
  • Principiantes

El triángulo de asteriscos es el primer ejercicio de bucles de casi cualquier curso, y en C++ es además el primero que muchos resuelven en un juez como Codeforces. C++ no te avisa de casi nada: si algo sale mal, el programa sigue como si nada. Aquí vemos dónde se esconden esos errores y cómo hacer que el compilador te ayude.

Lo vemos en tres niveles: básico (el triángulo y sus trampas), intermedio (la pirámide y sus variantes) y avanzado (Pascal, Sierpinski y la trampa de los paréntesis). Cada nivel termina con un reto. Para probar el código: g++ -std=c++17 -Wall triangulo.cpp -o triangulo && ./triangulo.

Juega con el triángulo

Antes de leer, elige un tipo y mueve el tamaño. Abajo ves lo que imprime y el código en C++ que lo hace; puedes copiarlo y probarlo.

Básico: el triángulo y sus trampas

El triángulo con un bucle

En la fila 1 va un asterisco, en la 2 van dos, en la 3 van tres: la fila y la cantidad son el mismo número.

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(i, '*') << "\n";
    }
}

  • for (int i = 1; i <= n; i++) cuenta del 1 al 5: empieza en 1, sigue mientras i sea menor o igual a 5 y suma 1 en cada vuelta.
  • std::string(i, '*') crea un texto con i asteriscos. Primero va la cantidad y después el carácter, entre comillas simples.
  • "\n" salta de línea. Se prefiere a std::endl, que además vacía la salida y hace más lento el programa cuando imprime mucho.

La trampa: la fila que falta

Por costumbre, muchos bucles en C++ se escriben desde 0 y con <. Aquí eso rompe el triángulo:

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 0; i < n; i++) {
        std::cout << std::string(i, '*') << "\n";
    }
}

Arriba sale una línea vacía (std::string(0, '*') es un texto vacío) y falta la fila de cinco, porque i < n se detiene en 4. Cuando el resultado tiene una fila de más o de menos, revisa dónde empieza el bucle y si la condición es < o <=.

Al revés

Para el triángulo invertido, el bucle empieza en n y resta 1 (i--):

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = n; i >= 1; i--) {
        std::cout << std::string(i, '*') << "\n";
    }
}

Que el usuario elija el tamaño

std::cin >> n lee un número de la entrada. Escribiendo 3:

#include <iostream>
#include <string>

int main() {
    int n;
    std::cin >> n;
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(i, '*') << "\n";

¿Y si el usuario escribe hola? C++ no da ningún error: cin falla en silencio, n queda en 0, el bucle no da ni una vuelta y el programa termina sin imprimir nada. Para darte cuenta, revisa si la lectura funcionó:

#include <iostream>
#include <string>

int main() {
    int n;
    if (!(std::cin >> n)) {
        std::cout << "Eso no es un número\n";
        return 1;
    }
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(i, '*') << "\n";
    }
}

Con dos bucles

Sin std::string(i, '*'), la fila se imprime con un bucle dentro de otro: el de afuera recorre las filas y el de adentro imprime un asterisco por vuelta.

#include <iostream>

int main() {
    int n = 4;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            std::cout << '*';
        }
        std::cout << "\n";
    }
}

Intermedio: la pirámide y sus variantes

Alineado a la derecha

Cada fila empieza con n - i espacios, así el triángulo queda pegado a la derecha:

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(n - i, ' ') << std::string(i, '*') << "\n";
    }
}

La pirámide

La pirámide crece de a dos asteriscos por fila (1, 3, 5, 7, 9) para que quede un centro: 2 * i - 1 asteriscos y n - i espacios.

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        std::cout << std::string(n - i, ' ') << std::string(2 * i - 1, '*') << "\n";
    }
}

Hueca

Solo el borde: la primera fila con un asterisco, la última llena y las del medio con un asterisco a cada lado y 2 * i - 3 espacios en el centro.

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        if (i == 1) {
            std::cout << std::string(n - 1, ' ') << "*\n";
        } else if (i == n) {
            std::cout << std::string(2 * n - 1, '*') << "\n";
        } else {
            std::cout << std::string(n - i, ' ') << "*" << std::string(2 * i - 3, ' ') << "*\n";
        }
    }
}

Con números

Cada fila cuenta del 1 al número de la fila, con un espacio entre números (pero no antes del primero, por eso el if (j > 1)):

#include <iostream>
#include <string>

int main() {
    int n = 5;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            if (j > 1) std::cout << " ";
            std::cout << j;
        }
        std::cout << "\n";
    }
}

La trampa del orden en std::string

std::string(3, '*') son tres asteriscos. Al revés, std::string('*', 3) compila sin quejarse, porque un carácter también es un número (el '*' vale 42):

#include <iostream>
#include <string>

int main() {
    std::string fila('*', 3);
    std::cout << fila.size() << "\n";
}
42

Son 42 caracteres invisibles (el carácter número 3). En pantalla parece que no imprimió nada, pero un juez lo marca como incorrecto.

Avanzado: Pascal, Sierpinski y los paréntesis

El triángulo de Pascal

Cada número es la suma de los dos que tiene encima, y los bordes son 1. Cada fila se arma a partir de la anterior, en un std::vector:

#include <iostream>
#include <string>
#include <vector>

int main() {
    int n = 5;
    std::vector<long long> fila = {1};
    for (int i = 0; i < n; i++) {
        std::cout << std::string(n - i - 1, ' ');
        for (size_t k = 0; k < fila.size(); k++) {
            if (k > 0) std::cout << " ";
            std::cout << fila[k];
        }
        std::cout << "\n";
        std::vector<long long> nueva = {1};
        for (size_t k = 0; k + 1 < fila.size(); k++) {
            nueva.push_back(fila[k] + fila[k + 1]);
        }
        nueva.push_back(1);
        fila = nueva;
    }
}

Un long long llega hasta 9223372036854775807. Con n de 68 o más, los números del centro ya no caben, y C++ no avisa: el resultado es un número equivocado (técnicamente, comportamiento indefinido). Con unsigned long long se gana una fila más; para filas más grandes hacen falta enteros grandes.

Sierpinski con asteriscos

Si en el triángulo de Pascal pintas solo los números impares, aparece el triángulo de Sierpinski. El de la fila i y la posición j es impar cuando (j & i) == j:

#include <iostream>
#include <string>

int main() {
    int n = 8;
    for (int i = 0; i < n; i++) {
        std::cout << std::string(n - i - 1, ' ');
        for (int j = 0; j <= i; j++) {
            if (j > 0) std::cout << " ";
            std::cout << ((j & i) == j ? "*" : " ");
        }
        std::cout << "\n";
    }
}

La trampa de los paréntesis

En C++, == se calcula antes que &. Sin paréntesis, j & i == j es j & (i == j), y el dibujo se rompe:

#include <iostream>
#include <string>

int main() {
    int n = 8;
    for (int i = 0; i < n; i++) {
        std::cout << std::string(n - i - 1, ' ');
        for (int j = 0; j <= i; j++) {
            if (j > 0) std::cout << " ";
            std::cout << (j & i == j ? "*" : " ");
        }
        std::cout << "\n";
    }
}

Por eso compilamos con -Wall: con esa opción, g++ avisa justo de esto.

warning: suggest parentheses around comparison in operand of ‘&’ [-Wparentheses]

Un aviso no detiene la compilación, así que es fácil no verlo. Acostúmbrate a compilar con -Wall y a leer lo que dice antes de ejecutar.

¿Y para dibujarlo?

C++ no trae nada para dibujar en una ventana. Hay librerías para eso (como SFML o SDL), pero piden instalar y configurar bastante para un primer programa. Si quieres ver el Sierpinski dibujado, tienes la versión en JavaScript, que se dibuja aquí mismo en el navegador, y la de Python con turtle.

Qué nos enseñó

Que el triángulo es una tabla (cuántos espacios y cuántos asteriscos en cada fila), igual que en cualquier lenguaje, y que en C++ los errores más caros son los que no hacen ruido: el cin que falla sin avisar, el std::string con los argumentos al revés, el número que no cabe y el operador que se calcula antes. Compila siempre con -Wall: muchas de esas trampas son un aviso que el compilador ya te estaba dando.

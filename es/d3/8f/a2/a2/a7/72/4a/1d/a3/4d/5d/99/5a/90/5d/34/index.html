¿Escribes la misma línea diez veces?

Casi todo programa repite algo: recorrer una lista de compras, pedir una contraseña hasta que sea correcta o dibujar una fila de asteriscos. Copiar la línea funciona, pero no escala; para eso están los ciclos.

En Python hay dos: for, para repetir sobre algo que ya conoces (una lista, un rango de números), y while, para repetir mientras se cumpla una condición. Los vemos con ejemplos cortos que puedes copiar y probar.

Con for recorres cada elemento de la lista de compras, uno por uno. En la línea 3, print muestra el elemento de esa vuelta.

compras.py
1compras = ["pan", "leche", "huevos"]2for item in compras:3    print(item)  # se repite una vez por cada elemento
